# HTML 交付规则

仅生成 HTML 时读取本文件。

- 默认单一自包含 HTML 和单一入口脚本；原件、索引等复现材料另行保留，不受数量限制。HTML 阅读不依赖外部 CDN 或在线资源，表格及已要求的图表内嵌；来源超链接允许联网查证。
- 项目中入口放已有源码目录、报告放交付目录；便携交付可同目录。路径相对于脚本或项目，输入/输出可显式指定，不依赖启动目录。
- 脚本默认生成后打开浏览器，提供关闭自动打开参数；无人值守或无法打开时给路径。用户另有要求优先，不因打开失败否定成功生成。
- 修改数据或规则后重跑生成，不手工修补生成 HTML 的统计结果。实际检查离线阅读、来源锚点和链接、长表排版、重跑数值一致性；没有浏览器核验条件时说明限制。
