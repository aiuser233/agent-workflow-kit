# 有来源的报告

普通文字答复、只查数据不自动进入本模式。先确定材料、口径、时期、读者、格式和验收；格式未指定时默认离线 HTML 与单一生成入口。Word/PDF 等指定格式优先，按需保留可编辑源文件。Excel、HTML、Word 等是交付偏好，不影响来源、真实计算和复现约束。图表遵循核心可视化开关。

## 通用规则

1. 列简洁材料清单，说明关键结论的依据；清单不构成额外审批。
2. 区分 `[F]` 可核验事实、`[C]` 按可追溯输入和公式实际计算的结果、`[I]` 推断、`[U]` 未知或无法验证。正文默认使用核验的 F/C，计算性质明确标记；用户要求 I/U 时独立标为推断或未证实，来源缺口不得伪装为事实。
3. 每个可核验事实和计算结论关联来源编号，包括用户内部材料中的事实。默认句尾上标，格式不支持时使用括号、脚注或尾注；表格可统一来源列/表注。同一来源与定位复用编号，混合来源列齐或拆句。
4. 来源条目给具体网址与访问日期，或本地文件和页码/工作表/字段/记录/段落；计算值给输入引用、公式及舍入规则。机构首页和文件名本身不足以定位。引用范围必须能支持对应事实。
5. 数据报告的数字从实际运行生成，入口完成读取、计算和生成所选格式；重跑以固定本地原件为依据，联网更新单列。纯文字报告不为套模板强造计算脚本，但仍保留材料与可核查引用。
6. 需要整理数据、维护持续项目或交付 exe 时才组合相应技能。先通过 harness 发现并加载，未发现可读取相邻 `../<技能名>/SKILL.md`；缺失报告限制，不假称已应用。

## 格式与验收

- 交付 HTML 时读取 [HTML 交付规则](references/html-delivery.md)。Word/PDF 不套用 HTML 的 CDN、浏览器自动打开或单文件规则；检查分页、字体、表格截断、脚注/尾注、可点击链接或可抄录地址，保留必要生成源和依赖。
- 核对正文/表格中的每个引用均有条目，编号无冲突，未引用条目按用途标为参考资料；逐项检查关键结论的定位和支持范围。
- 数据入口至少实际重跑一次，按约定精度比较表格和正文数值；时间戳等非数据差异不要求字节一致。重跑不能悄悄联网换原件。
- 交付所选格式、适用生成入口和必要复现材料；记录检查、依赖、运行方法与限制。格式检查通过不等于来源真实或数值正确，未运行部分明确标为未验证。
