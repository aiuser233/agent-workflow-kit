# 行为验收场景

以下用于新会话人工检查；静态检查、临时部署与 Git 机制测试不能替代两个宿主的实际业务验证。

| 请求 | 应加载/行为 | 应避免 |
| --- | --- | --- |
| 改写一句短文 | 核心，直接交付 | 项目脚手架、Git、可视化 |
| 先厘清数据需求，不要执行 | clarify-requirements，逐轮最多 3 问 | 未授权下载或生成结果 |
| 查某地区某时期官方统计数据 | source-data-research 的来源和数据参考 | 无源数据、暗中换指标、自动 HTML/图表 |
| 整理用户的内部 Excel | source-data-research 数据参考 | 强制换官方来源 |
| 生成带来源可复现报告 | source-backed-report，适用的数据参考 | 未证实推断混入正文、外部 CDN |
| 做成无 Python 可运行 exe | exe-delivery，适用项目/Git规则 | 宣称未做过的无 Python 验证 |
| 帮我 git 一下 | local-git-commit，核对已有暂存 | 混入无关改动、push |
| 讨论清理规则 | 核心/只读分析 | 实际清理 |
| 清理 ZCode 已删除对话残留 | cleanup-local-residue 的 zcode 参考 | Codex 表名、归档/成果/记忆删除 |
| 安装框架到自定义目录 | 总入口、adapter、plan/install | 推断技能路径、无授权覆盖冲突 |
| 用户 AGENTS 已有 Python 路径/个人规则 | 原文保留，框架区块追加；区块外要求优先 | 整份覆盖、自动删除冲突规则 |
| 重装或升级且用户新增区块外规则 | 一个区块，升级保留前后用户正文 | 重复追加、重写区块外内容 |
| 先讨论并给方案，敲定后再执行 | 澄清技能可交付可评审方案，状态为待定/未授权，等待实施授权 | 把方案本身也扣到授权之后、修改项目文件 |
| 已有 README/CHANGELOG 的小修 | 只更新过时说明，引用已有变更记录 | 重写 README、复制变更日志、凑空章节 |
| 内部工作簿含缺失和多来源计算 | 用最小字段映射唯一键、缺失原因、所有输入与公式；可用多个 sheet | 内部材料伪装官方数据、缺失填零、只留一个计算输入 |
| 指定 Word/PDF 带来源报告 | 通用事实/引用规则，指定格式的排版与脚注检查 | 强制另交 HTML、套用浏览器打开要求 |
| 数据报告重跑与引用验收 | 同一原件重跑，数值按精度一致，编号均可定位 | 只验证排版、重跑偷偷更新联网来源 |
| 长任务 exe 装在不可写目录 | GUI 响应、阶段进度、禁止重复启动、可选输出、错误后恢复 | 卡住 UI、虚构百分比、成功提示早于完整输出 |
| 同一文件含用户暂存/未暂存和任务块 | 分块隔离，提交后保留用户 staged/unstaged 内容；hook 失败核对 HEAD | 按文件全量提交、推进 HEAD 后遗留任务撤销、失败清空索引 |
| artifacts/image-cache 中有成果和附件 | 按真实身份保护，清单记录证据/引用/并发；脚本先副本或模拟验证 | 根据目录名或 ID 删除、直接在真实库试错 |
| 只提及另一技能名称但未读取 | 实际发现/读取入口，缺失则报告路径限制 | 假称加载或预加载所有技能 |
| 新用户无 Git 安装 | 标准库安装器先保存全部待改原件并读回校验 | 要求 Git、初始化配置仓库、备份失败仍安装 |
| 用户安装后新增个人规则并退出 | 卸载只移除框架区块，保留区块外新内容 | 完整旧文件覆盖新规则、删除其他技能 |
| 同名技能被覆盖并经历多次升级 | 卸载恢复首次安装前的文件；修改过的技能保留 | 仅回退最新升级、递归删整个目录 |
| 用户选择完全恢复安装前状态 | 预览影响、显式参数，先备份当前内容并返回安全收据 | 隐式强制覆盖、没有安全备份 |
| 卸载过程中中断 | 用卸载收据恢复配置和归属记录，再继续操作 | 继续安装覆盖不完整状态、删掉所有收据 |

自动化测试实际覆盖：两个 harness 目标部署、原配置追加/备份、编码和 BOM 保留、逐文件完整核验、无变化重装、区块外个人设置与升级、区块内改动冲突、授权更新与回滚、修改后回滚拒绝、源目录保护、ZCode skills 路径缺口拒绝和安装包独立验证。0.4.0 另验证强制备份失败/损坏保护、无 Git 环境部署、记录发现、保留个人设置的卸载及中断恢复；临时仓库验证 Git 隔离索引与失败 hook 保护。上述是脚本机制检查，不等于 AI 已在实际任务中正确执行技能。其余业务场景待宿主验收，未执行真实数据清理或数据库删除。符号链接真实测试仍因 Windows 权限跳过。
