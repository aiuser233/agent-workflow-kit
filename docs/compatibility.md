# 兼容性与路径依据

| 能力 | Codex | ZCode |
| --- | --- | --- |
| 通用核心和共同业务规则 | 由双源共同章节适配 | 由双源共同章节适配 |
| 清理参考 | `.codex` / `CODEX_HOME`、数据库及 rollout 线索 | `.zcode/cli`、`.zcode/v2`、表关联线索 |
| 目标 AGENTS 默认路径 | `CODEX_HOME/AGENTS.md`，回退 `~/.codex/AGENTS.md` | `~/.zcode/AGENTS.md`，据用户提供的实机报告确认 |
| 技能安装默认目录 | `CODEX_HOME/skills`，回退 `~/.codex/skills` | `~/.zcode/skills`，据实机报告确认；允许显式覆盖 |
| 文件部署、强制备份、回滚和卸载 | 临时目录测试通过，无 Git 必需依赖 | 实机报告确认安装、备份、历史查询、卸载和重装；回滚仅临时目录测试通过；无 Git 必需依赖 |
| 宿主技能自动发现 | 本次未进行新会话实测 | 实机报告显示全部 7 个技能；动态刷新与新会话扫描尚未区分 |
| UI 元数据 | 提供 `agents/openai.yaml` | 据实机报告被忽略；0.4.1 起安装时跳过 |
| 清理业务实际执行 | 本次未执行 | 本次未执行 |

路径依据是用户提供的原始规范、2026-10-16 提供的《agent-workflow-kit v0.4.0 —— ZCode 实机安装验证报告》（操作日期为 2026-10-14）和本机 skill-creator 说明。报告未提供 ZCode 版本或官方文档链接，不将其外推为所有版本的官方接口。用户名用当前用户环境解析，不写死示例用户名。

ZCode 的 `runtime_verified: true` 仅代表报告所覆盖的路径、部署、备份、卸载和技能发现；不代表 7 个技能的实际触发与业务质量、SQLite 清理或新会话刷新行为已经验收。旧 ZCode 安装留下的 `agents/openai.yaml` 不会在升级时自动删除；原收据管理的未修改文件可在卸载时处理。

`inspect` 只检查两种已知根路径是否存在；存在不能判定当前 harness，缺失也不能判定没有自定义安装。安装要求显式 `--harness`。新 harness 要增加明确加载路径、元数据兼容规则和业务专属参考，并完成部署与行为验证。
